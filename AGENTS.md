# fishjam_client — guide for contributors and AI agents

Flutter (iOS + Android) client SDK for Fishjam. Behavior is defined in [SPEC.md](SPEC.md); read the sections
for the module you touch before writing code. Golden message sequences live in `test/fixtures/`.

## Commands

The toolchain (Flutter, protoc) is pinned in `mise.toml`. Prefix every command with `mise exec --`.

| Task | Command |
|---|---|
| Install dependencies | `mise exec -- flutter pub get` |
| Analyze (must be clean) | `mise exec -- flutter analyze --fatal-infos` |
| Format check | `mise exec -- dart format --output=none --set-exit-if-changed .` |
| Tests | `mise exec -- flutter test` |
| Coverage gate (≥ 90 %) | `mise exec -- flutter test --coverage && tool/check_coverage.sh` |
| Regenerate protobuf bindings | `mise exec -- tool/gen_protos.sh <path to a fishjam-cloud/protos checkout>` |

Run analyze, format and tests before every commit.

## Rules

- **Red-green TDD is mandatory.** Write the test first, run it and observe it fail, then implement, then see
  it pass. Do not skip the observed failure.
- **Spec first.** Behavior changes start in `SPEC.md` (and the affected fixtures), then tests, then code.
  Reference sections in code comments as `SPEC §N`.
- **Stay in your module.** Each directory under `lib/src/` has an owner and a boundary (see the table below
  and the directory's `README.md`). Shared seams (`rtc/rtc_adapter.dart`, `signaling/transport.dart`,
  `models/`, `wire.dart`, `logger.dart`) change only with agreement of every module that uses them.
- **Pure Dart everywhere except the adapter.** Only `lib/src/rtc/flutter_webrtc_adapter.dart` may import
  `flutter_webrtc`. Everything else talks to `RtcAdapter` and is tested with `test/fakes/`.
- **Never hand-edit `lib/src/proto/`.** It is generated by `tool/gen_protos.sh` and excluded from analysis and
  coverage. The minimum compatible protos revision is recorded in the script.
- **Logging:** use the single `FishjamLogger` passed to your module (`debug`, `warn`, `error`). It prefixes
  lines with `[FISHJAM]`, logs only when the client was created with `debug: true`, and writes through
  `dart:developer`. Never use `print`.
- **Metadata JSON is never empty.** Encode with `encodeMetadataJson` (`null` → `"null"`), decode with
  `decodeMetadataJson` (SPEC §2.3).
- **Errors in the media event loop never escape.** Unknown ids are logged and ignored (SPEC §7).
- **New library files** must be added to `test/all_libraries_test.dart` (the test tells you), so coverage sees
  them.
- **This repository is public.** Do not reference private infrastructure, private repositories, internal
  service names or server implementation details in code, comments, tests, commit messages or PRs. Describe
  server behavior only as observable protocol behavior.

## Module ownership

| Directory | Owner | Boundary |
|---|---|---|
| `lib/src/rtc/` | Architect | `RtcAdapter` seam and the `flutter_webrtc` implementation |
| `lib/src/signaling/` | Signaling (transport: Architect) | socket, auth, close reasons, message queue, reconnection |
| `lib/src/engine/` | Engine | media event dispatch, negotiation state machine, command queue, peer connection, ICE |
| `lib/src/tracks/` | Tracks | local/remote track state, simulcast encodings, bandwidth, variants, VAD |
| `lib/src/data/` | Data & Stats | reliable/lossy data channels and `ChannelMessage` framing |
| `lib/src/stats/` | Data & Stats | periodic stats report, local audio level |
| `lib/src/livestream/` | Data & Stats | WHIP/WHEP |
| `lib/src/models/`, `wire.dart`, `logger.dart`, `version.dart` | Architect | public types and shared helpers |
| `lib/src/fishjam_client.dart`, `lib/fishjam_client.dart` | Integrator | the public facade; wiring only |
| `test/fakes/`, `test/support/`, `test/fixtures/` | Architect | fakes, fixture replayer, golden sequences |

Skeleton methods throw `UnimplementedError('<owner>')` until their owner implements them.

## Testing tools

- `test/fakes/fake_rtc.dart` — `FakeRtcAdapter` / `FakePeerConnection`: records every call (`calls`,
  `callsOf`), assigns mids on `setLocalDescription`, returns snapshot transceivers (re-fetch after
  `setLocalDescription` to read mids), and lets tests emit tracks, candidates, state changes and data channel
  events. `failNext(method, error)` scripts failures.
- `test/fakes/fake_transport.dart` — `FakeTransport` / `FakeTransportFactory`: records sent frames,
  `nextSent()`, `receive(PeerMessage)`, `serverClose(code:, reason:)`, `loseConnection()`.
- `test/support/fixtures.dart` — `Fixture.load(name)` and `FixtureReplayer` replay a golden sequence against a
  client wired to the fakes; `describeEvent` gives the JSON form of events used by `expect` steps. The step
  format is in SPEC §23.

## Versioning

The package version follows the Fishjam web SDK release train (lockstep). `lib/src/version.dart` must equal
`version` in `pubspec.yaml` (a test enforces it); the `sdkVersion` sent on authentication is
`flutter-<version>`.
